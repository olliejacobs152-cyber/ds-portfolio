**Job Posting 1: Junior Data Scientist – Government** 

Required skills:
-	Coding in R and python
-	ArcGIS skills
- Either a relevant degree or relevant experience
- Data Extraction
- Analytical skills

Preferred skills: 
- Able to use AI to code
- Data Mining

**Job Posting 2: Junior Business and Marketing Data Scientist – Internet / Software**

Required: 
-	Bachelor’s degree
-	Coding in R, Python and SQL
-	Data cleaning
-	Extract, compile, and validate data
-	Analytical skills
-	Data extraction

**Skills in both postings:**
- Coding in R and Python
- Data extraction
- Analytical skills

The thing that surprised me most about comparing these two postings was how specific 
the requirements and qualifications were for both of them. The government job required
extensive knowledge of Geographic Information Systems (GIS), and the Internet/ Software
job required knowledge of a structured programming technique using R, Python and SQL.
The only real similarities between the two posting were the coding languages (R and Python)
that they both required proficiency in. This was surprising because they were both junior 
roles, so I thought that they would require broader data analysis skills that would be more 
common for Data Scientists at this level.
